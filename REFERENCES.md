# REFERENCES

Documentação, repositórios e endpoints públicos utilizados pelo projeto:

- **FIFA API v3:** `https://api.fifa.com/api/v3`
  - Calendário, jogos, súmulas, escalações oficiais e live timeline.
- **FotMob Data API:** `https://www.fotmob.com/api/data`
  - Opta match ratings, xG detalhado, estatísticas de passe, tabelas de ligas (Brasileirão `268`, Libertadores `45`, Champions League `42`, Premier League `47`, Eliminatórias `10199`) e perfis de seleções/clubes (Brasil `8256`).
- **ge.globo RSS:** Feeds públicos de notícias de futebol
  - Seleção Brasileira: `https://ge.globo.com/rss/ge/futebol/selecao-brasileira/`
  - Brasileirão Série A: `https://ge.globo.com/rss/ge/futebol/brasileirao-serie-a/`
  - Copa do Brasil: `https://ge.globo.com/rss/ge/futebol/copa-do-brasil/`
  - Copa Libertadores: `https://ge.globo.com/rss/ge/futebol/libertadores/`
  - UEFA Champions League: `https://ge.globo.com/rss/ge/futebol/futebol-internacional/liga-dos-campeoes/`
- **QuickChart:** `https://quickchart.io`
  - Geração stateless de cards PNG (artilharia, cartões, mapa de intensidade).
- **Telegram Bot API:** `https://core.telegram.org/bots/api`
  - Disparo de mensagens e imagens com formatação MarkdownV2/HTML.
- **Base Actions Repository:** `https://github.com/juninmd/base-actions`
  - Padrão centralizado de workflows CI/CD `@main`.
